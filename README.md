# 🛠️ Điều Khiển Nhóm Robot Theo Đội Hình Và Vận Chuyển Vật Thể Trong Môi Trường Động

[![Demo Video](https://img.youtube.com/vi/_nwCx7ETgss/0.jpg)](https://youtu.be/_nwCx7ETgss?si=vbbwcJKr2gyPgUpn)

## 🧭 Giới Thiệu

Dự án tập trung vào việc **điều khiển nhóm robot gồm 3 robot** hoạt động theo **đội hình nhất định**, thực hiện nhiệm vụ **quét bản đồ** và **cùng vận chuyển một vật thể** trong môi trường có chứa cả **vật cản tĩnh và vật cản động**.

Hệ thống đảm bảo:
- **Giữ vững đội hình khi di chuyển**
- **Cộng tác vận chuyển vật thể**
- **Né tránh thông minh các vật cản thay đổi theo thời gian**

## 📌 Tính Năng Chính

- 🤖 Điều khiển 3 robot di chuyển theo đội hình
- 🧱 Vận chuyển vật thể bằng sự phối hợp giữa các robot
- 🗺️ Quét bản đồ và xây dựng môi trường làm việc
- 🚧 Né tránh vật cản tĩnh và vật cản động
- 🔄 Cập nhật lộ trình liên tục trong môi trường động
- 🧠 Điều khiển phân tán (decentralized coordination)

## 🔧 Công Nghệ Sử Dụng

- **ROS (Robot Operating System)**  
- **Ngôn ngữ:** C++, Python  
- **Các thư viện/stack phổ biến:**  iris, snopt
